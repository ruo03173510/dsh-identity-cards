## 三、目录与引用

```yaml
# card.md front-matter
resources:
  format: shared:templates/report-format.md
  rules: shared:rules/report.rules.json
  good: project:course-graph/reports/style_compare/v3_current
  bad: project:course-graph/reports/style_compare/v2_rejected_word
  series: private:series/machine-learning
```

`project:<名字>/...` 的名字来自一张登记表，根变了只改表，卡不动：

```text
# ~/.dsh/cards/@shared/projects.md
| 名字 | 根 | 备注 |

| machine-learning | D:\pythoncode\machine_learning | 机器学习 exp1-exp4 |
```

缺名字时等于当前工作区。查表是 O(1)，不遍历。
